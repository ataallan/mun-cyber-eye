Train from labeled data

Calls vision.train_activity.train_activity_model. CPU sklearn training is typically a few seconds — this request waits for the result.

Train object model

Optional CPU sklearn classifier on data/objects/ frames. Needs at least two catalog classes with a few images each. Runtime inventory still prefers YOLO; this checkpoint is not used to invent objects on real uploads. Does not replace or break activity training.

Activate checkpoint

Writes the chosen path to data/active_checkpoint.json. The running app and create_adapter read that file when present; otherwise they use ACTIVITY_CHECKPOINT. No secrets are edited.

Upload labeled frames

Add authorized, site-specific examples (game, dance, confrontation, fall, …) without SSH. Category names are validated; path traversal is rejected. Sport zips may use train/game_or_play__basketball/*.jpg, train/game_or_play/basketball/*.jpg, or train/basketball/*.jpg. Scene tags use train/scene__street/*.jpg or train/game_or_play__scene__street/*.jpg.

Place tags help the scene-context assist. Catalog or any typed setting (slugified). Custom places have no synthetic painter. They are not a claim the model understands every sports arena. Uniforms are not labeled as identity or guilt.

Extract frames from video

Upload an authorized mp4 / avi / mov / mkv. The existing FrameSampler writes JPEGs into the chosen label folder. Videos are sampled to frames; the sklearn activity trainer still learns from images. Path traversal is rejected. Object-class frames go to data/objects/train/<object_id>/. Dangerous-object frames go to data/dangerous/train/<id>/. Activity class potential_weapon_object remains available under “activity class”.

Authorized sources only. After extract, use Train from labeled data for activity classes, or Train object model when enough object images exist.
